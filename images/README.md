# 사진 폴더

여기에 아래 이름으로 사진 파일을 넣으면, **이 페이지를 여는 모든 사람**(학생 포함)에게
그 사진이 기본으로 보입니다. 이름과 확장자만 맞으면 되고, 없는 항목은 원래 그림이 그대로 쓰입니다.

| 파일 이름 | 무엇을 바꾸나요 | 어울리는 사진 |
|---|---|---|
| `bg.jpg` (또는 `.png`) | 배경 (강 풍경) | 화면을 꽉 채우는, 가로로 넓은 사진 |
| `traveler.png` | 어르신 (건너는 사람) | 배경이 투명한 PNG |
| `kid.png` | 아이 (돌을 던지는 사람) | 배경이 투명한 PNG |
| `stone.png` | 돌 | 정사각형에 가까운 사진 (글씨가 위에 겹쳐 보임) |
| `hit.png` | 틀린 돌에 맞았을 때 어르신 모습 | 배경이 투명한 PNG, `traveler.png`와 비슷한 크기·구도 |

확장자는 `jpg`, `jpeg`, `png`, `webp` 중 아무거나 사용할 수 있습니다.

> 화면 위쪽 "사진 바꾸기" 버튼으로 올린 사진은 그 사람의 브라우저에만 적용됩니다(미리보기용).
> 학생 모두에게 적용하려면 그 패널에서 **파일로 저장**을 눌러 받은 파일을 이 폴더에 넣어야 합니다.
