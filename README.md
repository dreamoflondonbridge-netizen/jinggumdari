# 🪨 논증 징검다리

중학교 국어 **'연역과 귀납 논증'** 단원 학습용 웹 게임입니다.
문장이 적힌 돌을 순서대로 던져 강에 징검다리를 놓고, 건너편 어르신을 건네 드립니다.

`index.html` 파일 하나로 되어 있어 브라우저로 열기만 하면 바로 실행됩니다.

## 태블릿에서 바로 열기 (GitHub Pages)

1. **Settings** 탭 → 왼쪽 메뉴 **Pages**
2. **Source** 는 `Deploy from a branch`, **Branch** 는 `main` / `/ (root)` 선택 후 **Save**
3. 1~2분 뒤 아래 주소가 열립니다

   **https://dreamoflondonbridge-netizen.github.io/jinggumdari/**

> 레포가 **Private** 이면 Pages 는 유료 플랜에서만 동작합니다.
> 무료 계정이라면 Settings 맨 아래에서 **Public** 으로 바꿔 주세요.

## 규칙

| 차례 | 귀납 논증 | 연역 논증 |
|---|---|---|
| 1 | 구체적 사실 (전제 1) | 일반적 원리 (대전제) |
| 2 | 구체적 사실 (전제 2) | 구체적 사실 (소전제) |
| 3 | 일반적 결론 | 결론 |
| 4 | `귀납` 돌 | `연역` 돌 |

- 돌을 누른 뒤 **강 화면을 꾹 눌렀다 떼면** 던져집니다. (누른 위치 = 방향, 누른 시간 = 힘)
- 내용이 틀린 돌은 물에 빠지고 **기회 1개 · 40점**이 깎입니다. 조준만 빗나간 것은 감점이 없습니다.
- 3단계부터 **바람**이 붑니다. 조준이 어려우면 위쪽 `조준 도움` 을 켜세요.
- 키보드: `Space` 길게 눌렀다 떼기 = 던지기, `←` `→` = 방향 조절

## 수업에서 쓸 때

- 소리는 화면을 한 번 누른 뒤부터 납니다. **아이패드는 측면 무음 스위치를 꺼 주세요.**
- 최고 점수와 열린 스테이지는 **그 기기 안에** 저장됩니다. 기기를 바꾸면 기록도 사라집니다.
- 인터넷이 없어도 작동합니다. (글꼴만 온라인일 때 적용되고, 오프라인이면 기본 글꼴로 대체)
- 시작 화면에서 스테이지를 골라 바로 시작할 수 있습니다.

## 문제 고치기

`index.html` 을 메모장이나 VS Code 로 열어 `const STAGES = [` 부분만 손보면 됩니다.

```javascript
{ type:'귀납',                       // '귀납' 또는 '연역'
  topic:'참새와 비둘기',              // 안내판에 뜨는 소재 이름 (정답을 알려 주지 않는 말로)
  premises:['참새는 알을 낳는다.','비둘기도 알을 낳는다.'],
  conclusion:'그러므로 모든 새는 알을 낳는다.' }
```

- `연역` 은 `premises` 를 `[대전제, 소전제]` 순서로 적어야 합니다.
- `귀납` 은 두 전제의 순서를 가리지 않습니다.
- 논증 방식 돌(`귀납`/`연역`)은 각 스테이지의 `type` 값에서 자동으로 만들어집니다.
- 점수 배점은 `resolveThrow` 함수의 `120`, `60`, `40` 값을 고치면 됩니다.
